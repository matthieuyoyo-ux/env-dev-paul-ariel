## Hébergement du dépôt : GitHub

* **Décision :** Utiliser GitHub comme plateforme d'hébergement distant pour ce projet.
* **Autres possibilités :** GitLab, Bitbucket, Gitea (auto-hébergé).
* **Raison :** Interface répandue, gratuite pour les dépôts publics et privés, et bien intégrée avec VS Code et les outils du cours.
